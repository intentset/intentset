# People keep control of what their agents build

## Rationale

Agents write code faster than anyone can read it, so a team can no longer understand its product by reading every change. Intentset keeps what a product promises, which code delivers each promise and how it is checked, in readable records the agents update with every change, so that people review the product rather than the diff.
